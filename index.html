I'm an engineer working in the Canadian oil and gas industry, focused on pressure-containing equipment, wellhead systems, and the API and ISO standards that govern them. The tools on this site started as personal reference aids — lookups and dimensional checks I was doing by hand — and became something worth publishing.

Every tool is built for real field conditions: fast to load, readable on mobile, and precise enough to be useful without replacing a licensed engineer's judgement. All outputs carry a disclaimer for exactly that reason. The goal is to cut the friction between a standard and the information you actually need on-site.

More tools are in progress. If you work in the same space and have a reference problem worth solving, I'd like to hear about it.
